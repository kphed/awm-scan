# awm-scan

AWM (Asset Wealth Management) Scan is a dedicated JPM MONY explorer designed to accelerate AWM team comprehension, increase decision velocity, and establish product-owned visibility over the protocol.

## App Features

## App Features

* **MONY Architecture Map:** A visual topology of MONY's smart contracts (the Diamond proxy and its underlying facets). It untangles the protocol's architecture to provide immediate clarity on module relationships, administrative permissions, and emitted events.
* **Product Translation Layer:** A plain-English demystifier that translates complex on-chain modules into tangible business capabilities. This layer bridges the gap between engineering and product by outlining exactly what each facet enables, the operational constraints it imposes, and the governance mechanisms required for future modifications.
* **Live Protocol Observability:** A real-time telemetry feed indexing mainnet events. This layer moves beyond static documentation to surface live transfers, mints, burns, and administrative actions, directly linking the theoretical protocol architecture to its live on-chain execution.
